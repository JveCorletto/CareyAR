# Imágenes de CareyAR

El poster opcional del visor 3D debe colocarse con este nombre exacto:

`public/images/turtle-poster.webp`

La aplicación utiliza esa ruta como poster de `<model-viewer>`.

Si el archivo todavía no existe, el área del visor conserva un fondo CSS y la aplicación continúa funcionando.

Recomendaciones para el poster:

- Formato WebP.
- Peso aproximado menor a 150–200 KB cuando sea posible.
- Relación horizontal o cuadrada que funcione bien en teléfonos.
- Incluir únicamente imágenes con licencia compatible con la exposición.
